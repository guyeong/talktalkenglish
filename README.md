# TalkTalk English v2.3 v2.0

아이 영어책 사진을 등록하고, Gemini Vision으로 문장과 단어 위치를 한 번 분석한 뒤 반복해서 읽는 로컬 우선 영어 리더입니다.

## v2.0 핵심 개선

- 두 쪽 펼침 사진을 좌우 페이지로 자동 분할해 각각 분석
- AI 전송 이미지를 페이지별 최대 1280px로 축소하고 글자 대비 보정
- 시간 초과된 구간만 960px로 자동 재시도
- `gemini-3.1-flash-lite` 저지연 멀티모달 모델 사용
- 현재 페이지만 분석하거나 책의 미분석 페이지를 순차 분석
- 분석 결과는 IndexedDB에 저장되어 같은 페이지를 다시 호출하지 않음
- 전체 화면 리더, 단어/문장 터치 발음, 전체 읽기, 따라 읽기 유지

## 로컬 실행

1. 프로젝트 최상위에 `.env` 파일을 만들고 아래 한 줄을 입력합니다.

```env
GEMINI_API_KEY=새_Gemini_API_키
```

2. 최초 1회 설치:

```powershell
npm.cmd install
```

3. AI 기능을 포함해 실행:

```powershell
npx.cmd netlify dev
```

4. 브라우저에서 `http://localhost:8888` 접속

> `.env`는 GitHub에 올리지 마세요. 화면에 노출된 키는 즉시 폐기하고 새 키를 사용하세요.

## v2.0.1 음성 API 호환성 수정

2026년 Gemini Interactions API의 레거시 스키마 종료에 대응했습니다.
고음질 음성 생성은 Interactions API 대신 공식적으로 지원되는
`models.generateContent` TTS 방식으로 호출합니다.

## v2.1 변경 사항

- 고음질 음성 3종: 미국식 여성, 영국식 남성, 호주식 여성
- 전체 화면에서 이미지의 실제 표시 영역과 OCR 좌표를 정확히 일치시킴
- 터치 영역의 배경색을 제거하여 영어 글자를 가리지 않음
- 터치 영역은 기본적으로 숨김이며, 필요할 때 윤곽선만 표시
- iPhone/iPad Safari용 `viewport-fit=cover`, 홈 화면 아이콘, PWA manifest, service worker 추가

## Netlify 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Netlify에서 `Import an existing project`로 저장소를 연결합니다.
3. Site configuration → Environment variables에 `GEMINI_API_KEY`를 추가합니다.
4. 배포가 완료되면 발급된 HTTPS 주소를 iPhone/iPad Safari에서 엽니다.
5. Safari 공유 버튼 → `홈 화면에 추가`를 선택하면 앱처럼 실행됩니다.

빌드 명령과 Functions 경로는 `netlify.toml`에 포함되어 있습니다.

## v2.2 변경사항
- 멈춤 버튼을 `멈춤 / 계속 읽기` 토글 버튼으로 변경했습니다.
- 전체 읽기와 따라 읽기 모두 멈춘 위치에서 재개합니다.
- 전체 화면 컨트롤에도 동일한 토글 동작을 적용했습니다.


## v2.3 따라 읽기 발음 평가

- 문장을 먼저 들려준 후 마이크 자동 녹음
- 단어 정확도와 발음 명료도 AI 평가
- 종합 80점 이상이면 다음 문장으로 자동 이동
- 80점 미만이면 같은 문장을 다시 들려주고 재도전
- 인식된 문장과 다시 연습할 단어 표시
- iPhone/iPad Safari에서는 HTTPS 배포 주소에서 마이크 권한 허용 필요

평가 점수는 교육용 참고 지표이며 전문 음성검사 결과가 아닙니다.

## v2.6 읽기 위치 기능

- 멈춤 후 Gemini 음성을 같은 초 위치에서 이어서 재생합니다.
- 페이지 읽기 위치 스크롤에서 원하는 문장을 선택하면 해당 문장부터 읽습니다.
- 일반 화면과 전체 화면에서 모두 사용할 수 있습니다.

## v2.7 변경 사항

- `따라 읽기`와 `따라 읽기 평가`를 별도 버튼으로 제공합니다.
- 읽는 동안 현재 문장과 전체 문장 흐름을 화면에서 따라볼 수 있습니다.
- 평가 통과 기준은 90점입니다.
- 아이가 말을 마친 뒤 침묵을 감지해 녹음을 자동 종료하고 곧바로 평가를 시작합니다.

## v3.1 추가 사항
- 읽기 버튼과 설정이 화면 아래로 잘리지 않도록 전체 리더 레이아웃을 수정했습니다.
- iPhone 기본 사진 형식인 HEIC/HEIF를 선택하면 브라우저에서 JPEG로 변환합니다.
- 변환은 `heic-to` 1.5.2 브라우저 빌드를 필요할 때만 불러와 수행합니다.

## v3.2 감정 동화 낭독

- 낭독 스타일: `또렷하게 / 동화책처럼 / 연극처럼`
- 전체 읽기에서 내레이션과 대화체를 구분하고, 문장부호와 대화 동사를 바탕으로 감정을 표현합니다.
- 따라 읽기와 발음 평가는 학습 정확도를 위해 감정을 줄인 또렷한 음성을 사용합니다.
- 감정 처리는 OCR에 포함하지 않고 TTS 요청 안에서만 처리하므로 OCR 요청 수가 늘어나지 않습니다.
- OCR은 저지연 문서 추출용 `gemini-3.5-flash-lite`를 사용합니다.
